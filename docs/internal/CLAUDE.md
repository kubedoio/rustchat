## Design System

RustChat has an explicit design system in `DESIGN.md` (repo root). Before
making visual or UI decisions, read `DESIGN.md` for font, color, spacing, and
aesthetic direction. Do not deviate without explicit user approval. In QA
mode, flag any UI that does not match `DESIGN.md`.

This is a UI-direction convention consistent with the architecture vision in
`DESIGN.md`; it does not change any agent path, ownership, or governance rule
defined in `AGENTS.md` / `.governance/**`.
