## How to Be Listed

1. Make a contribution (code, docs, tests, design, bug reports, or feedback).
2. Open a PR adding your GitHub username and a brief description of your contribution to this file.
3. Follow the existing format and place yourself in alphabetical order.

## Recognition

- Git commit history
